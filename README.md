# global-terrorism-eda

This repository contains an exploratory data analysis (EDA) of the Global Terrorism Dataset performed in a Jupyter notebook.

Files
- global_terrorism_eda.ipynb — the main notebook with data loading, cleaning, analysis and visualizations.

Quick start
1. Clone the repository or open it locally.
2. (Recommended) Create and activate a virtual environment:
   - python -m venv .venv
   - .\.venv\Scripts\Activate
3. Install common data-science packages (if you don't have them):
   - pip install pandas numpy matplotlib seaborn plotly jupyter
4. Launch Jupyter and open the notebook:
   - jupyter notebook global_terrorism_eda.ipynb

Notes
- The notebook includes raw data processing and visualizations — take care when re-running heavy cells if large datasets are present.
- If a requirements.txt is added later, use pip install -r requirements.txt to install exact dependencies.
